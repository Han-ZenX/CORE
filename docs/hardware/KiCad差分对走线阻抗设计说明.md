# KiCad 差分对走线阻抗设计说明

差分线是否要走 50Ω 微带线？

> 结论：**不是。** 差分线要按"差分阻抗（Zdiff）"设计，而不是按 50Ω 单端阻抗设计。

---

## 1. 概念区分

| 线型 | 目标阻抗 | 典型用途 |
|------|----------|----------|
| 单端微带线 | 50Ω（射频常用），一般 40~60Ω | 时钟、单端高速信号、RF |
| 差分对 | 差分阻抗 Zdiff = 90Ω / 100Ω 等 | USB、以太网、HDMI、MIPI、LVDS |

### 常见接口的差分阻抗规范

| 接口 | 差分阻抗 Zdiff | 容差 |
|------|----------------|------|
| USB 2.0（D+/D-） | 90Ω | ±10% |
| USB 3.x / PCIe / SATA | 100Ω | ±10% |
| HDMI / Ethernet | 100Ω | ±10% |
| MIPI D-PHY | 100Ω | ±10% |
| LVDS | 100Ω | ±10% |

---

## 2. 为什么不能直接"每根走 50Ω"

差分阻抗与单端阻抗的关系为：

```
Zdiff = 2 x Z0 x (1 - k)
```

其中 Z0 为单根线的单端阻抗，k 为两根线之间的耦合系数。

- 若两线**间距很大**（弱耦合，k → 0）：Zdiff ≈ 2 × 50 = 100Ω，此时"每根 50Ω"确实近似成立；
- 但差分对通常是**紧耦合**布线（线间距 ≈ 线宽），k 明显不为 0。若仍照搬单端 50Ω 的线宽与间距，Zdiff 会掉到 80~90Ω，无法满足 100Ω ±10% 的要求。

正确做法：**使用差分阻抗计算器，同时解出线宽 W 与线间距 S**，而不是先算 50Ω 单端阻抗再照抄线宽。

---

## 3. KiCad 中的具体操作流程

1. **先向板厂索取叠层表**（层间介质厚度、介电常数 Dk、铜厚、阻焊厚度）。阻抗完全由叠层决定，没有叠层信息就无法计算。
2. 用 KiCad 自带的 `工具(T) / Tools` → `计算工具 / Calculator Tools` → `高速 / High Speed` → `传输线 / Transmission Lines`，或板厂提供的阻抗计算表 / Saturn PCB Toolkit / Polar SI9000，算出 W 与 S。
3. 在 `电路板配置 / Board Setup` → `设计规则 / Design Rules` → `网络类 / Net Classes` 中为差分网络设置 `Track Width`、`Diff Pair Width`、`差分对间隙 / Diff Pair Gap` 以及 `Diff Pair Via Gap`。
4. 使用**差分对布线工具**（快捷键 `6`）走线，再用 `布线(U) / Route` → `Tune Differential Pair Skew`（快捷键 `9`）完成对内等长调整。

---

## 4. 实践中的注意事项

- **必须有完整的参考平面。** 差分对正下方的 GND 平面不能有割缝，跨分割会同时破坏阻抗连续性和回流路径。
- **对内等长优先于对间等长。** 对内 skew 一般控制在 5 mil 以内；USB 2.0 可放宽至约 50 mil，但越小越好。
- **短走线可以不做严格阻抗控制。** 若 USB 2.0 走线仅 2~3 cm 且为低速/全速，阻抗失配的影响通常可以接受；但 USB HS（480 Mbps）及以上建议严格执行。
- **两层板做不好阻抗控制。** 1.6 mm FR4 两层板要做 90Ω 差分，线宽会非常宽且耦合很差。高速差分建议至少四层板（信号 - GND - 电源 - 信号）。

---

说明：具体的 W/S 数值依赖实际叠层参数，需针对本项目的接口类型与板层数单独计算后填入。计算方法见《KiCad 传输线计算器使用说明》。
